🔧 Gerenciar Banco de Dados

Configure a conexão com Firebase para rastrear inscrições em tempo real.

Como obter essas informações:

  1. Acesse console.firebase.google.com
  2. Crie um novo projeto (ou use um existente)
  3. Vá em Configurações do Projeto → Chaves e Credenciais
  4. Copie a API Key, Project ID e Database URL
  5. Cole aqui e clique em "Conectar"
